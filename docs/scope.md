# Scope of use

This utility changes display settings on the machine it runs on. Use it only on systems you
own or administer, or where you have explicit permission to change display configuration.

It is designed for the case where a desktop suite you legitimately run reconfigures the
layout in a way that conflicts with your own configuration.

It does not:

- modify, patch or redistribute any third-party software,
- bypass licensing, authentication or access controls,
- interact with remote services.

Nothing in this repository targets a specific product or vendor. Configuration values such
as process names and display identifier prefixes are supplied by the user.
